# Design Context — AS-CRM

## Users

Sales reps and operators at **ActivateSwag**, a custom apparel and promotional products
company. They live in this CRM all day, moving inbound deals through the pipeline from
inquiry → qualified → order request → design → payment → close.

The pipeline includes:

- **Lead Received → Qualified Buyer → Order Request → Design Ready → Pending Payment →
  Closed Won / Closed Lost** (matches their HubSpot configuration exactly)
- Lead-gen tooling shipped in `preview/sales-lead-generation`: lead scoring (0–100),
  source category attribution, dedup detection, disqualification reason capture, public
  capture endpoint with UTM persistence, free email enrichment.

Operating context: desktop, full screen, multi-monitor. Power users. They are *triaging*
not browsing — every visual element is judged on whether it speeds up triage.

## Brand Personality

Three words: **operational, decisive, unfussed.** This is software for people who run
real production. It should feel like the inside of a well-organized warehouse, not a
SaaS landing page. Confidence without theatrics.

Emotions to evoke: clarity, momentum, control. Not delight, not "fun."

## Aesthetic Direction

### Reference points

- **HubSpot Deals** (the customer's actual board, screenshot in
  `/home/carlos/active_projects/Reference Images/Hubspot Reference 1.png`) — the
  information architecture is the target: flat cards, plain stage column headers, light
  filter chrome, sparing color, dense vertical layout.
- **DESIGN_SPEC.md** documents the project's existing token system (Tailwind v4
  defaults, system font stack, slate-heavy palette with blue/emerald/cyan accents,
  cyan→blue scrollbar/checkbox signature, radii 6/8/10/14, the `from-slate-50 via-white
  to-blue-50/30` page gradient).

### Anti-references

- HubSpot's orange CTA — replace with the AS-CRM indigo→violet gradient that's already
  our primary action color.
- The current AS-CRM lead module's gradient stage column headers and colored top accent
  strips on every card — too decorated, slows triage.
- "AI dashboard" tropes: cyan-on-dark, purple-to-blue text gradients, neon glows,
  glassmorphism, hero metric cards.

### Theme

**Light**, with the existing AS-CRM page gradient (`from-slate-50 via-white to-blue-50/30`)
preserved. Reps work in well-lit rooms, often with HubSpot open in another tab — light
matches the comparison context.

### Typography

System sans (Tailwind v4 default stack). No custom fonts. Per DESIGN_SPEC this is
non-negotiable for cohesion across the platform.

Hierarchy through size and weight, never gradient text or decorative effects:

- Page title: `text-2xl font-bold`
- Stage column headers: `text-[11px] font-semibold uppercase tracking-wider`
- Deal title: `text-sm font-semibold`
- Meta: `text-[11px] text-slate-500`

### Color

Following the existing token system:

- **Surface**: white cards on `from-slate-50 via-white to-blue-50/30` page bg
- **Text**: `slate-900` body, `slate-500` secondary, `slate-400` tertiary
- **Primary**: `from-indigo-600 to-violet-600` gradient (CTA only)
- **Stage colors**: keep the existing 7-stage palette as small color dots, not
  backgrounds. Stages are recognized by position + label, not by full color washes.
- **Accent**: cyan→blue gradient for interaction signatures (scrollbar, focus rings,
  selected states) — preserves the AS-CRM signature noted in DESIGN_SPEC.
- **Score badge** is the *only* element on a card that uses saturated color. That's
  intentional — it's the punctuation that drives triage.

## Design Principles

1. **Triage-first density.** Every pixel justifies itself by helping a rep decide
   whether to act on a deal. If it doesn't help triage, remove it.
2. **One vivid element per card.** The score badge. Everything else is monochrome,
   typographic, or a 2px color dot. Vividness becomes a wayfinding tool.
3. **Chrome is invisible.** Filters, headers, and stage columns recede so the deals
   themselves are the page. No gradient stage backgrounds, no metric cards, no big
   icon-in-rounded-square headers.
4. **Match HubSpot's IA, render in AS-CRM's tokens.** Layout decisions come from
   HubSpot. Color, weight, radii, and gradient choices come from DESIGN_SPEC.
5. **Preserve the lead-gen functionality.** Score badges, dedup modal, disqualify
   modal, embed snippet, source category filter, min-score filter, lead-gen field
   wiring — all stay. The redesign is visual, not functional.
